# ArenaPass - Billetterie

## Présentation du projet

ArenaPass est un site web de billetterie en ligne permettant
aux utilisateurs de découvrir des événements sportifs,
notamment des sports de niche, et d'acheter leurs billets
directement sur la plateforme.

L'objectif du projet est de faciliter l'accès aux événements
sportifs moins médiatisés grâce à une plateforme simple,
accessible et intuitive.
